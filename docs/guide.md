# 操作ガイド

View and Edit の使い方を、やりたいことごとにまとめたページです。
キーの一覧だけ見たいときは [README の「主なキー」](../README.md#主なキー) を、
画面の中では `?`（エディタでは `F1`）を押してください。

## 1. 開く

開き方は 3 つあります。どれも herdr の画面の上にポップアップが出ます。

| こんなとき | すること | 開くもの |
|---|---|---|
| 画面に出ているファイルを開きたい | **何も選ばずに** `prefix+f` | 画面に出ているファイルの一覧（選ぶと開きます） |
| 決まったパスを開きたい | パスを**ダブルクリックで選んで** `prefix+f` | そのファイル（フォルダならその中） |
| `file://` のリンクになっている | **Ctrl を押しながらクリック** | そのファイル |

- `prefix+f` は README の「キーの割り当て」で設定したキーです。別のキーにした場合は読み替えてください。
- `src/app.py:120` のように行番号が付いていれば、その行を開きます。
- `REQUIREMENTS.md` のような**ファイル名だけ**でも、プロジェクト（Git リポジトリ）の中から探して開きます。
  同じ名前のファイルが複数あるときは、一覧から選びます。
- 画面にファイルが 1 つも出ていないときは、今いるフォルダのファイルブラウザが開きます。
- 画面に出ていないファイルは、一覧やファイルブラウザで `f` を押して名前の一部から探せます（[3. ファイルを探して見る](#3-ファイルを探して見る)）。
- ファイルを開いたときも、`q` で戻ると元の一覧（またはそのファイルがあるフォルダ）に戻ります。

## 2. 画面の見方

画面は 5 種類です。どの画面でも、**いちばん下の行に今使える操作**が出ています。

### 画面のファイル一覧（何も選ばずに `prefix+f` を押したとき）

```
 画面に出ているファイル                                    3 項目
   ..  フォルダを見る（ファイルブラウザ）  │ Markdown  2 KB   ← 右は選んだものの中身
 ▸ …/very/long/folder/final-report.md      │
   src/app.py:120                          │ # はじめに
   ../docs/REQUIREMENTS.md                 │ ...
 ↑↓ 移動  Enter 開く  e 編集  / 絞り込み  ← フォルダを見る  q 閉じる
```

- 画面の**下の方に出ていたもの（新しいもの）ほど上**に並びます。
- 長いパスは、ファイル名が見えるように先頭を `…` で省きます。
- ペインのフォルダの近くにあるファイルは `../docs/…` のように短く表示します。
- いちばん上の `..`（フォルダを見る）か `←` で、今いるフォルダのファイルブラウザに移れます。

### ファイルブラウザ

```
 ~/project                                   12 項目   ← 今いるフォルダ
   ..                                  │ Markdown  2 KB   ← 右は選んだものの中身
   src/                                │
 ▸ README.md                  2.1 KB   │ # はじめに
   package.json                 1 KB   │ ...
 ↑↓ 移動  Enter 開く  ← 上へ  / 絞り込み  e 編集  n 新規  q 閉じる  ? ヘルプ
```

左に一覧、右に選んだもののプレビューが出ます。選ぶだけで中身が見えるので、開かなくても確認できます。
一覧のいちばん上の `..`（画面では「上のフォルダへ」と表示）は、ひとつ上のフォルダに戻る行です。

### ファイル名で探す（一覧やファイルブラウザで `f` を押したとき）

```
 探す: appmod                              3 件   ← 打った文字と、当たった数
 ▸ src/deep/app_module.py      36 B   │ 1 line1       ← 右は選んだものの中身
   tests/app_module_test.py   120 B   │ 2 line2
 ↑↓ 選ぶ  Enter 開く  Esc 戻る
```

- 打つたびに一覧が絞り込まれ、いちばん当たりのよいものが選ばれます。
- 開いたファイルを `q` で閉じると、打った文字はそのままでこの画面に戻ります。

### ビューア（ファイルを開いたとき）

```
 report.xlsx  ~/project                                  表計算  1.9 KB
  表   プレビュー   Tab で切替   ◀ 1/2 ▶ 売上   ← 表示の切り替えとページ
 （中身）
 ← 前ページ  → 次ページ  ↑↓ スクロール  Tab 表示切替  o アプリで開く  q 戻る
```

2 行目に、表示の種類（表・プレビュー・ソースなど）とページ（シート・スライド）が出ます。

### エディタ（`e` で編集を始めたとき）

```
 notes.md ●  ~/project                            3:12  UTF-8 LF
 1  # メモ
 2
 3  今日やること
 ^S 保存  ^Q 閉じる  ^F 検索  ^Z 元に戻す  ^C コピー  ^X 切取  ^V 貼付
```

- ファイル名の横の `●` は「まだ保存していない変更がある」しるしです。
- 右上は、カーソルの位置（行:列）と、文字コード・改行の種類です。保存しても変わりません。

## 3. ファイルを探して見る

| やりたいこと | キー | マウス |
|---|---|---|
| 選ぶ | `↑` `↓` | クリック |
| 開く（フォルダなら中へ） | `Enter` | ダブルクリック |
| ひとつ上のフォルダへ | `←` | 一覧のいちばん上の `..` をクリック |
| 一覧をスクロール | `PgUp` `PgDn` / `g` `G`（先頭・末尾） | ホイール |
| 名前で絞り込む | `/` のあと名前の一部を入力 | — |
| 隠しファイルも見る | `.` | — |
| ホームフォルダへ | `~` | — |

**絞り込みのコツ:** `/` を押して `repo` と打つと、名前に「repo」を含むものだけが残ります。
`Enter` で絞り込んだまま一覧に戻り、`Esc` で解除します。

### プロジェクト全体から名前で探す（`f`）

`/` の絞り込みは今のフォルダの中だけですが、`f` は**下のフォルダも含めたプロジェクト全体**から探します。

1. 一覧かファイルブラウザで `f` を押す
2. 名前の一部を打つ（例: `appmod` → `src/deep/app_module.py`）
3. `↑` `↓` で選んで `Enter`（フォルダを選ぶと、その中をファイルブラウザで開きます）

- 文字が**順番どおりに含まれていれば**当たります。飛び飛びでもかまいません（`srcag` → `src/agent.py`）。
  大文字・小文字とスペースは区別しません。
- ファイル名に当たったもの、続けて当たったもの、短いパスほど上に並びます。
- 探す範囲は、見ているフォルダを含む Git リポジトリ全体です（Git の外ではそのフォルダの中）。
  `.gitignore` で除外したファイル（`node_modules` など）は出ません。
- 表示は上位 200 件までです。多すぎるときは、もう少し長く打って絞り込んでください。
- `Backspace` で 1 文字、`Ctrl+U` で全部消せます。`Esc` で元の画面に戻ります。

## 4. 中身を見る（形式ごとのコツ）

| 形式 | できること |
|---|---|
| ソースコード・テキスト | 行番号と色分けで表示。`/` で検索、`n` `N` で次・前へ |
| Markdown | 整形して表示。`Tab` で元の文章（ソース）に切り替え |
| HTML | ブラウザで見たときの見た目を表示。`Tab` でテキストだけ・ソースに切り替え |
| 画像 | その場で表示（HEIC や SVG も可） |
| 動画・音声 | `Space` で再生・一時停止、`←` `→` で 5 秒戻る・送る |
| PDF | `←` `→` でページ送り。`Tab` でテキストだけの表示 |
| Excel | 表で表示。`←` `→` でシートを切り替え |
| PowerPoint | スライドの見た目。`←` `→` でスライド送り、`Tab` で文字だけの表示 |
| Word | 見た目の表示。`Tab` でテキストだけの表示 |
| CSV・JSON・SQLite | 表や整形した形で表示。SQLite は `←` `→` でテーブルを切り替え |

どの形式でも、次の操作が使えます。

- `o` … Finder で開くときと同じ、いつものアプリで開く（Excel ファイルなら Excel など）
- `c` … ファイルの場所（パス）をコピー
- `r` … 読み込み直す（ほかのアプリで書き換えたあとに）

大きなファイルや音声は、ブラウザの右側ではなく `Enter` で開いてから表示・再生します。

## 5. 編集して保存する

1. ファイルを選んで（または開いて）`e` を押す
2. 普通のメモ帳と同じように書き換える
3. `Ctrl+S` で保存（下の `^S 保存` をクリックしても同じ）
4. `Ctrl+Q` で閉じる

- 保存しないで閉じようとすると「変更を保存しますか？」と聞かれます。
  `保存して閉じる` / `保存せず閉じる` / `編集に戻る` から選びます。
- 編集中にほかのアプリがそのファイルを書き換えていた場合は、上書きする前に確認します。
- よく使うキー: `Ctrl+Z` 元に戻す、`Ctrl+Y` やり直し、`Ctrl+F` 検索、`Ctrl+G` 行番号を指定して移動、
  `Shift+矢印` で選択（マウスのドラッグや Shift+クリックでも選択できます）。
- 画像や PDF など、文字のファイルでないものは編集できません（`o` でいつものアプリを開けます）。

## 6. ファイルやフォルダを作る・名前を変える・捨てる

ファイルブラウザで次のキーを押します。

| やりたいこと | キー | 補足 |
|---|---|---|
| 新しいファイルを作る | `n` → 名前を入力 → `Enter` | エディタが開きます。**保存したときに**ファイルができます |
| 新しいフォルダを作る | `m` → 名前を入力 → `Enter` | |
| 名前を変える | `r` → 新しい名前 → `Enter` | |
| ゴミ箱に移す | `d` → `はい` | 完全には消えません。Finder のゴミ箱から戻せます |

名前の入力中は `Esc` でやめられます。

## 7. マウスだけで使う

キーを覚えていなくても、次のところはクリックで操作できます。

- **いちばん下の行の案内**（`Enter 開く`、`q 閉じる`、`^S 保存` など）… 押すとそのキーを押したのと同じ
- **一覧** … クリックで選ぶ、ダブルクリックで開く、いちばん上の `..` で上のフォルダへ（画面のファイル一覧ではファイルブラウザへ）
- **ビューアの 2 行目** … `表` `プレビュー` などの名前で表示を切り替え、`◀` `▶` でページ送り
- **動画・音声の再生の行**（`▶ 再生中 0:03 / 0:10` の行）… 再生・一時停止
- **確認の質問**（「ゴミ箱に移動しますか？」など）… `はい` `いいえ` などのボタン
- **ヘルプ画面** … どこかをクリックすると閉じる
- **ホイール** … 一覧・プレビュー・中身をスクロール

名前の入力（新しいファイル名、絞り込み、`f` で探す名前）だけは、キーボードで打ちます。

## 8. 困ったとき

| 困りごと | 原因と対処 |
|---|---|
| `prefix+f` を押しても何も起きない | キーの割り当てが読み込まれていません。README の「キーの割り当て」を書き足して `herdr server reload-config` を実行してください |
| 「View and Edit はすでに開いています」と出る | ポップアップは同時に 1 つだけです。開いている方を `q` で閉じてからもう一度開いてください |
| パスをクリックしても開かない | リンクになっていないパスは、クリックだけでは開けません。何も選ばずに `prefix+f` を押して一覧から選ぶか、ダブルクリックで選んでから `prefix+f` を押してください |
| 一覧に出したいファイルが出ない | 一覧に出るのは、いまペインに**見えている範囲**で、実際にあるファイルだけです。スクロールで隠れたものや、まだ作られていないファイルは出ません |
| 「ファイルが見つかりません」と出る | ファイル名から探す範囲は、ペインのフォルダを含む Git リポジトリの中です（Git の外ではペインのフォルダの中）。別の場所のファイルは、`~/` から始まるパスか絶対パスで選んでください |
| 「一部だけ探しました」と出る | Git の外の大きなフォルダでは、待たせすぎないよう約 1 秒で探すのを打ち切ります。見つからないときは、もう少し長いパス（`docs/a.md` など）で選んでください |
| `f` で探したファイルが出ない | 探す範囲は、見ているフォルダを含む Git リポジトリの中です。`.gitignore` で除外したファイルは出ません。別のプロジェクトのファイルは、そのフォルダへ移ってから `f` を押してください |
| 「大きいフォルダなので一部だけ探しています」と出る | Git の外の大きなフォルダでは、待たせすぎないよう約 3 秒でファイル名の読み取りを打ち切ります。もっと下のフォルダへ移ってから `f` を押すと、見つかりやすくなります |
| 画像・動画・PDF が表示されない | 画像を表示できる端末（Ghostty、kitty、WezTerm など）が必要です |
| 動画が再生できない | `brew install ffmpeg` で ffmpeg を入れてください。入れなくても最初の 1 コマは表示されます |
| PDF が 1 ページ目しか出ない | `brew install poppler` でページ送りができるようになります |
| HTML の日本語が文字化けする | Google Chrome があると正しく表示できます。無い場合は macOS の簡易表示（クイックルック）を使うため、文字コードの指定がないページは化けることがあります |
| 「この形式は内蔵エディタで編集できません」と出る | 文字のファイルではありません。`o` でいつものアプリを開いてください |
| 捨てたファイルを戻したい | Finder のゴミ箱から「戻す」を選んでください |
